# 🛍️ پرامپت مخصوص Hostinger AI Builder
### نسخهٔ سریع برای ساخت فروشگاه با خود بیلدر هاستینگر (بدون کدنویسی)

> **این پرامپت برای چی خوبه:** راه‌اندازی سریع یک فروشگاه پوشاک کودک روی پلتفرم هاستینگر (در چند دقیقه، بدون کد).
> **برای چی خوب نیست:** پرو آنلاین آواتار، اتوماسیون ۹۰ ثانیه‌ای، انتشار ۱۰ شبکه، درگاه پرداخت ایرانی، دیتابیس اختصاصی. آن‌ها فقط با پرامپت `18-master-build-prompt.md` (نسخه کد اختصاصی) ساخته می‌شوند — جدول مقایسه انتهای همین فایل.

---

## ۱) طرز استفاده (گام‌به‌گام)

1. وارد **Hostinger → AI Website Builder** شو و «ایجاد سایت جدید» / «ساخت با هوش مصنوعی» را بزن.
2. بیلدر سه سؤال اول را می‌پرسد — این‌طور جواب بده:
   - **Brand name:** `مینی رویال` (یا نام برند انتخابی‌ات)
   - **Website purpose / نوع:** `Online store — kids clothing (فروشگاه پوشاک کودک)`
   - **Description:** بلوک پرامپت اصلی (بخش ۲) را کامل کپی کن.
3. بعد از ساخت اولیه، **یک‌یک** دستورهای بخش ۳ را به ترتیب بده (بین هر دستور صبر کن تا کامل شود).
4. بعد از اتمام، بخش ۴ (تنظیمات دستی) را انجام بده.

---

## ۲) ⭐ پرامپت اصلی (کپی کن — زیر ۱۹۵۰ کاراکتر)

```text
یک فروشگاه آنلاین پوشاک کودک و نوجوان (۰ تا ۱۷ سال، تمرکز ۲ تا ۱۲ سال) بساز: پسرانه، دخترانه و یونیسکس؛ تیشرت، شلوار، پیراهن/شومیز، کاپشن، سرهمی نوزاد، ست، لباس مدرسه، لباس مجلسی، اکسسوری.

سبک: مدرن، شاد و کودکانه ولی حرفه‌ای؛ پالت روشن ملایم (کرم، صورتی ملایم، آبی آسمانی، سبز نعنایی)؛ تمیز، راست‌چین (RTL) و کاملاً موبایل‌ریسپانسیو؛ فونت وزیرمتن؛ تصاویر بزرگ و فضای سفید زیاد.

صفحات: خانه؛ فروشگاه (همه محصولات)؛ دسته‌ها (پسرانه، دخترانه، نوزاد، لباس مدرسه، مجلسی، ست، اکسسوری)؛ صفحه محصول؛ سبد خرید؛ تسویه؛ درباره ما؛ تماس با ما؛ وبلاگ؛ سوالات متداول؛ قوانین و مقررات؛ حریم خصوصی؛ شرایط بازگشت کالا.

صفحه اصلی: هدر با لوگو+جستجو+سبد خرید؛ اسلایدر کمپین؛ بخش «جدیدترین‌ها»؛ «پرفروش‌ترین‌ها»؛ «پیشنهاد ویژه با تخفیف»؛ دسته‌های پرطرفدار با تصویر؛ بنر فصلی (بازگشت به مدرسه، عید، یلدا)؛ نظرات والدین؛ خبرنامه؛ مزایا (ارسال سریع، بازگشت ۷ روزه، پرداخت در محل، پارچه باکیفیت)؛ فوتر کامل با شبکه‌های اجتماعی.

صفحه محصول: گالری چندتصویری با زوم؛ انتخاب سایز (بر اساس سن/قد) و رنگ با نمایش موجودی؛ جدول سایز سانتی‌متری؛ قیمت + قیمت قبلی + درصد تخفیف؛ امتیاز و نظرات مشتریان؛ دکمه «موجود شد خبرم کن»؛ محصولات مرتبط؛ آکاردئون سوالات متداول درباره جنس و شست‌وشو؛ دکمه اشتراک واتساپ/تلگرام.

فروشگاه: کوپن تخفیف؛ ارسال رایگان بالای مبلغ مشخص؛ محاسبه هزینه ارسال بر اساس شهر؛ گزینه پرداخت در محل؛ مدیریت سفارش و موجودی.

لحن محتوا: مهربان، ساده و قابل‌اعتماد برای والدین؛ تاکید بر جنس پارچه، راحتی و دوام. محتوا فارسی.

سئو: متا تایتل و دیسکریپشن؛ breadcrumb؛ اسکیما؛ سرعت بالا. لینک اینستاگرام، تلگرام و واتساپ در هدر/فوتر.
```

## ۳) دستورهای بعدی (یک‌به‌یک کپی و بده)

```text
1) حالا ۲۰ محصول نمونه پوشاک کودک اضافه کن با اسم واقعی، قیمت، سایزبندی سنی (مثلاً ۲-۳، ۴-۵، ۶-۷ سال)، رنگ‌ها و جدول سایز هر محصول، و برای هر دسته حداقل ۳ محصول.
```

```text
2) به صفحه دسته‌بندی فیلتر اضافه کن: سایز، رنگ، جنسیت، بازه قیمت، تخفیف‌دار + مرتب‌سازی (جدیدترین، پرفروش، ارزان، گران).
```

```text
3) کوپن «WELCOME10» = ۱۰٪ تخفیف اولین خرید + «ارسال رایگان بالای [مبلغ مشخص]» را تنظیم کن و بنر آن را بالای سایت بگذار.
```

```text
4) روی هر صفحه محصول یک «ماشین‌حساب راهنمای سایز» تعاملی اضافه کن: والدین قد، وزن و سن کودک را وارد کنند → سایز پیشنهادی همان محصول نمایش داده شود.
```

```text
5) وبلاگ را با ۳ مقاله آماده کن: «راهنمای کامل سایز پوشاک کودک»، «راهنمای خرید لباس مدرسه»، «بهترین جنس پارچه برای نوزاد» — هر کدام ۳۰۰ کلمه با لینک به محصولات مرتبط.
```

```text
6) یک دکمه شناور چت واتساپ/تلگرام به همه صفحات اضافه کن.
```

```text
7) صفحه «قوانین و مقررات» را کامل کن: بازگشت کالا تا ۷ روز، راهنمای شست‌وشو، نحوه ارسال و پیگیری سفارش.
```

```text
8) بخش نظرات و امتیازدهی (۱ تا ۵ ستاره) را روی صفحه محصول فعال کن و نظرات تأییدشده را با نشان سبز نمایش بده.
```

```text
9) صفحه ۴۰۴ و پیام «سبد خرید خالی» را شخصی‌سازی کن و دکمه «بازگشت به فروشگاه» بگذار.
```

```text
10) سایت را دوزبانه کن: فارسی (پیش‌فرض، راست‌چین) + انگلیسی؛ سوئیچ زبان در هدر.
```

## ۴) تنظیمات دستی بعد از ساخت (بیلدر خودش انجام نمی‌دهد)

- [ ] **دامنه:** دامنهٔ `.ir` را از ثبت‌کنندهٔ ایرانی بخر (برای اینماد لازم است) و روی سایت بیلدر ست کن.
- [ ] **پرداخت:** بیلدر هاستینگر فقط Stripe / PayPal / dLocal دارد → **برای فروش داخل ایران** فعلاً گزینه «پرداخت در محل (COD)» را فعال کن و دکمهٔ «پرداخت آنلاین» را به لینک زرین‌پال/زیبال خودت هدایت کن.
- [ ] **ارسال:** زون‌های ارسال برای استان‌های ایران + هزینه بر اساس وزن/شهر را تنظیم کن.
- [ ] **اینماد/جواز:** شروع کن (سایت باید صفحات قانونی و اطلاعات تماس کامل داشته باشد).
- [ ] **تصاویر واقعی:** عکس‌های محصولات را با عکس‌های واقعی باکیفیت جایگزین کن (واترمارک برند).
- [ ] **سئو:** متاها، آدرس‌های فارسی و اتصال به Google Search Console را نهایی کن.
- [ ] **پیامک/اطلاع‌رسانی:** برای OTP و پیگیری سفارش باید سرویس پیامک ایرانی را از بیرون وصل کنی (بیلدر سرویس داخلی ندارد).

## ۵) مهم — این‌ها را بیلدر هاستینگر نمی‌سازد (و راه‌حلش)

| قابلیت (از بلوپرینت) | بیلدر هاستینگر | راه‌حل درست |
|---|---|---|
| فروشگاه + سبد + کوپن + بلاگ + سئو پایه | ✅ می‌سازد | همین پرامپت کافی است |
| توصیه سایز ساده (فرم → پیشنهاد سایز) | 🟡 تقریباً (اگر «ماشین‌حساب تعاملی» ساخت) | دستور شماره ۴ |
| جدول سایز، گالری، موجودی زنده | ✅ می‌سازد | طبق پرامپت اصلی |
| ⭐ پرو آنلاین سطح ۲ (آواتار کودک + ست‌کردن + اشتراک) | ❌ نمی‌سازد | فقط کد اختصاصی (پرامپت ۱۸، Sprint 5) |
| اتوماسیون ۹۰ ثانیه‌ای + انتشار خودکار ۱۰ شبکه | ❌ نمی‌سازد | فقط کد اختصاصی (پرامپت ۱۸، Sprint 6) |
| درگاه ایرانی (زرین‌پال/زیبال) + پیامک ایرانی | ❌ ندارد | فقط سایت روی هاست ایران (میزبان‌فا) |
| دیتابیس ۲۹ جدولی اختصاصی + پنل ادمین پیشرفته | ❌ ندارد | فقط کد اختصاصی |

**پیشنهاد استراتژیک:** از بیلدر هاستینگر برای **MVP سریع** (همین امروز تا ۲ هفته، برای تست بازار و گرفتن سفارش اول) استفاده کن، و **به‌صورت موازی** ساخت سایت کامل اختصاصی با پرامپت ۱۸ را جلو ببر (همان کد می‌تواند بعداً روی میزبان‌فا/هاستینگر برود).
