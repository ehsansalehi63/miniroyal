# گزارش بررسی سرویس پیامک — ۱۴۰۵/۰۶/۱۳

اسکریپت `node scripts/check-sms.cjs` اجرا شد.

| مورد | نتیجه |
|---|---|
| تست‌های داخلی مسیر OTP | ۲۳ موفق، ۰ ناموفق |
| پیکربندی فعلی sandbox | بدون کلید واقعی در محیط توسعه؛ ارسال واقعی انجام نشد |
| حالت console در production | به‌درستی خطا می‌دهد و موفقیت کاذب ندارد |
| ایران‌پیامک | پاسخ ۴۰۱ کلید نامعتبر به‌درستی به خطا تبدیل می‌شود |
| کاوه‌نگار | status داخلی ۵۰۱ حتی با HTTP 200 به‌درستی خطا تشخیص داده می‌شود |
| SMS.ir | status=0 با HTTP 200 به‌درستی خطا تشخیص داده می‌شود |
| خطای شبکه/DNS | پیام خطای فارسی و قابل فهم تولید می‌شود |

برای فعال‌سازی روی Hostinger باید `SMS_PROVIDER`، `SMS_API_KEY` و بسته به سرویس `SMS_LINE_NUMBER`، `SMS_PATTERN_CODE` یا `SMSIR_TEMPLATE_ID` در محیط Node.js تنظیم شوند؛ سپس برنامه با environment جدید restart شود. تا زمانی که این مقدارها از پنل سرویس پیامک وارد نشوند، نمی‌توان ارسال واقعی به شمارهٔ مشتری را تأیید کرد.
