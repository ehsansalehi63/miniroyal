# 👕 مینی رویال — فروشگاه پوشاک کودک و نوجوان

**فروشگاه اینترنتی پوشاک کودک و نوجوان «مینی رویال (Mini Royal)»** با سطح امکانات دیجی‌کالا + ⭐ پرو آنلاین لباس (Virtual Try-On) + موتور اتوماسیون ۹۰ ثانیه‌ای.

- **برند:** مینی رویال / Mini Royal
- **محصول:** پوشاک کودک و نوجوان ۰ تا ۱۷ (تمرکز ۲ تا ۱۲ سال) — پسرانه، دخترانه، یونیسکس
- **درگاه پرداخت:** زرین‌پال (در توسعه: حالت sandbox — بدون پول واقعی)
- **زیرساخت هدف:** میزبان‌فا (سایت ایرانی) + هاستینگر (موتور AI و شبکه‌های اجتماعی)

> بلوپرینت کامل کسب‌وکار و معماری در `_ARENA_DELIVERABLES/` ریپوی
> [ehsansalehi63/ehsansalehi.ir](https://github.com/ehsansalehi63/ehsansalehi.ir) موجود است (اسناد ۰۱ تا ۱۷). این ریپو خانهٔ اصلی توسعه است.

## 🗺️ نقشهٔ ساخت (اسپرینت‌ها)

- **S0** ✅ پایهٔ Next.js + RTL/فونت فارسی (وزیرمتن) — انجام شد
- **S1** کاتالوگ: صفحه اصلی کامل، دسته/فیلتر، جستجو، صفحه محصول
- **S2** خرید: سبد، تسویه، درگاه زرین‌پال (sandbox)، کوپن، رهگیری
- **S3** حساب کاربری + صفحات قانونی + نظرات
- **S4** پنل ادمین (KPI، محصول/سفارش/مشتری، RBAC)
- **S5** ⭐ پرو آنلاین: توصیه سایز هوشمند + آواتار کودک
- **S6** موتور اتوماسیون ۹ ایستگاهی (عکس → محصول → انتشار سوشال)
- **S7** رشد: بلاگ AI، سئو، باشگاه مشتریان، باکس فصلی، B2B

## 🧱 استک

Next.js 16 (RSC/Server Actions/ISR و Turbopack) · TypeScript strict · Tailwind v4 · Framer Motion (به‌زودی) · MySQL (به‌زودی) · zod (به‌زودی) · PWA (به‌زودی) · RTL فارسی (وزیرمتن)
